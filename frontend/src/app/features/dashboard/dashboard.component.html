Como interpretar os indicadores

Os equipamentos considerados têm cadastro ativo. “Ativos” representa os que não possuem corretiva aberta; “em falha”, os que possuem ao menos uma. A disponibilidade é uma fotografia desse estado. OS abertas e backlog incluem todas as pendências do escopo, mesmo anteriores ao período dos gráficos.

MTTR: média entre início do atendimento e conclusão das corretivas encerradas no período com horários válidos. MTBF requer horas efetivas de operação e ainda não é calculado. Ordens preditivas não possuem cadastro específico. As últimas OS seguem o período selecionado; links abrem a lista correspondente.
